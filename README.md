# The Laravel Project Cafe

A playful, interactive landing page about **Laravel projects ideas for building backend development skills**, designed like a late night cafe menu. Pick a roast level, add project dishes to your tray, and watch a personal learning plan build itself.

## What is inside

- A project menu with ten Laravel ideas, from a first blog to a full project management system
- Filters by level: Starter, Intermediate and Advanced
- A live receipt and tray that count build weeks, skills tasted and plan strength
- A copy my plan button to share your picks
- Course pairings and a reading shelf with fully clickable links
- Responsive layout, scroll reveal animations and a reading progress bar

## Project ideas on the menu

Personal Blog, Task Tracker, URL Shortener, Library System, Clinic Booking, Shop Inventory and Billing, Job Portal, Project Management System, Laravel and React Dashboard, and a Store with PayPal and WhatsApp alerts.

## Run it locally

It is a single static file. Open `index.html` in any browser. No build step and no dependencies.

## Deploy with GitHub Pages

1. Push the repository to GitHub.
2. Open Settings, then Pages.
3. Choose the main branch and the root folder, then save.
4. Your page goes live at `https://your-username.github.io/laravel-project-cafe/`.

## Design notes

Palette: black, blue, white, brown and teal. Typography uses system fonts only, so the page loads fast and works offline.
